# Dive into LLMs —《动手学大模型》系列编程实践教程

- **地址**：https://github.com/Lordog/dive-into-llms
- **来源**：上海交通大学《自然语言处理前沿技术》（NIS8021）、《人工智能安全技术》（NIS3353）课程讲义
- **负责人**：[张倬胜](https://bcmi.sjtu.edu.cn/home/zhangzs/)（上海交通大学）
- **性质**：公益教程，完全免费
- **分类**：AI 学习资源

## 简介

《动手学大模型》是由上海交通大学张倬胜老师团队开发的 LLM 入门编程实践教程。通过简单实践帮助学生快速入门大模型，适合课程设计和学术研究参考。每章包含课件（PDF）、教程文档和可运行的 Jupyter Notebook。

## 教程内容

| 章节 | 主题 | 简介 |
|------|------|------|
| 1 | 微调与部署 | 预训练模型微调与部署指南，选择合适模型在特定任务上微调并部署为 Demo |
| 2 | 提示学习与思维链 | 大模型 API 调用与推理指南，探索 Prompt Engineering 技巧 |
| 3 | 知识编辑 | 语言模型编辑方法和工具，操控模型对指定知识的记忆 |
| 4 | 数学推理 | 让大模型学会数学推理，快速蒸馏一个迷你 R1 |
| 5 | 模型水印 | 在语言模型生成内容中嵌入人类不可见的文本水印 |
| 6 | 越狱攻击 | 了解越狱攻击如何突破大模型安全防护，从攻击角度理解安全 |
| 7 | 大模型隐写 | 让大模型在流畅回答时悄悄携带隐蔽信息（"看不见的墨水"） |
| 8 | 多模态模型 | 多模态大语言模型的理解与生成能力实践 |
| 9 | GUI 智能体 | 让 AI Agent 替你点外卖、回消息、购物比价，解放双手 |
| 10 | 智能体安全 | 大模型在开放智能体场景中的风险意识与防护 |
| 11 | RLHF 安全对齐 | 基于 PPO 的 RLHF 实验指南，大模型与人类价值观对齐 |

## 扩展：国产化《大模型开发全流程》

联合华为昇腾社区推出，基于昇腾基础软硬件开发，包含初级、中级、高级系列课程，覆盖 PPT、实验手册、视频等形式，提供从快速上手到模型迁移调优的全流程开发指南。
