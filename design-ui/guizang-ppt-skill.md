# Guizang PPT Skill（歸藏 PPT 技能）

- **地址**：https://github.com/op7418/guizang-ppt-skill
- **作者**：歸藏（op7418）
- **协议**：MIT
- **分类**：设计与 UI

## 简介

适配 Claude Code / Codex 等 Agent 环境的 HTML 演示文稿生成 Skill。内置两套视觉系统——电子杂志风（Style A）和瑞士国际主义风（Style B），输出单文件 HTML 横向翻页 PPT，同时支持 PPT 配图和多平台封面生成。

由歸藏在线下分享"一人公司：被 AI 折叠的组织"等演讲中沉淀而来，踩过的坑都写进了 checklist。

## 核心特性

**双视觉系统**

- **Style A 电子杂志风**：类似 Monocle 杂志版式，适合叙事、观点表达、个人风格。10 种页面布局，5 套电子墨水主题
- **Style B 瑞士国际主义**：网格至上、高饱和锚点色、直角、发丝线、极致字号对比。22 种锁定版式（S01-S22），4 套锚点色主题

**PPT 能力**

- 横向翻页演示：键盘/滚轮/触屏/底部圆点/ESC 索引多种交互
- 低性能静态模式：按 B 键关闭 WebGL/Canvas 动画
- 单文件 HTML 输出，浏览器直接打开

**配图与封面**

- Codex 环境下可调用 GPT-Image 2.0 / GPT-M 2.0 生成纪实照片、信息图、流程图、UI 情景图
- 多平台封面：公众号 21:9 头图、1:1 分享卡、小红书 3:4、视频号横版
- 截图再设计：CleanShot X 式背景画布适配

## 设计原则

1. **克制优于炫技** — WebGL 背景只在 hero 页透出
2. **结构优于装饰** — 靠字号/字体对比/网格留白，不用阴影和浮动卡片
3. **图片是第一公民** — 对齐内容区，比例稳定
4. **配图只做素材** — 不把页脚、标题、角标画进图片
5. **瑞士风必须守版式** — 只从 22 种锁定版式中选择，不临时发明

## 亮点 / 个人评价

这个项目的核心价值在于"约束即质量"的理念——不允许自定义颜色、瑞士风只能从 22 种版式中选择、配图不能自带装饰元素。这些看似限制的规则，实际上让 AI 生成的 PPT 保持在可接受的美学水准之上。双视觉系统的设计也很聪明：电子杂志风适合个人表达，瑞士风适合事实和产品展示。瑞士风还配套了版式校验器 `validate-swiss-deck.mjs`，可以自动拦截不符合规范的页面结构，这在 AI 生成内容的场景中非常实用。
