# Awesome

- **地址**：https://github.com/sindresorhus/awesome
- **作者**：Sindre Sorhus（ prolific open-source maintainer）
- **协议**：CC0-1.0
- **分类**：搜索与知识管理
- **标签**：精选列表、资源索引、开源生态

## 简介

GitHub 上最著名的精选列表（Awesome List）的鼻祖和总索引。收录了各技术领域的优质资源合集，覆盖平台、编程语言、前后端开发、计算机科学、安全、游戏开发等 27 个大类、数百个子列表。几乎所有知名开源项目都有对应的 Awesome List。

## 亮点 / 个人评价

- **资源发现入口**：当你想了解某个技术领域有哪些好工具/库/框架时，先来这里查对应的 Awesome List
- **社区驱动**：每个子列表都有专人维护，质量经过社区筛选
- **快速导航**：访问 [awesome.re](https://awesome.re/) 即可直达
- **生态规模**：GitHub 上有数千个 Awesome List，本仓库是总目录和规范制定者
- **规范参考**：定义了 Awesome List 的编写标准（[awesome.md](https://github.com/sindresorhus/awesome/blob/main/awesome.md)），新列表需遵循其贡献指南
