# Awesome-Selfhosted

- **地址**：https://github.com/awesome-selfhosted/awesome-selfhosted
- **在线版**：https://awesome-selfhosted.net/（推荐）
- **协议**：各项目各自的开源协议
- **分类**：搜索与知识管理

## 简介

最全面的自托管（Self-hosted）自由软件资源列表。收录了可以在自己的服务器上部署和管理的网络服务和 Web 应用，替代 SaaS 服务。项目涵盖从博客、邮件、文件同步到监控、分析等几乎所有常见服务类型。

## 资源规模

收录数百个开源项目，按功能分为 60+ 个分类。

## 主要分类

| 分类 | 典型项目 |
|------|---------|
| 自动化 | n8n, Huginn, Apache Airflow |
| 备份 | Duplicati, BorgBackup, Restic |
| 博客 | Ghost, WordPress, Hugo |

| 邮件完整方案 | Mailcow, Mail-in-a-Box, Maddy |
| 社交网络 & 论坛 | Discourse, Flarum, Mastodon |
| 视频会议 | Jitsi Meet, BigBlueButton |
| 文件同步 | Syncthing, Nextcloud, Seafile |
| DNS | Pi-hole, AdGuard Home, CoreDNS |
| CMS | WordPress, Strapi, Ghost |
| CRM | Dolibarr, SuiteCRM, Monica |
| 监控 | Grafana, Zabbix, Uptime Kuma |
| 笔记 | Outline, Wiki.js, Hedgedoc |
| 代理 | Nginx Proxy Manager, Traefik, Caddy |
| 个性化 | Homer, Dashy, Homepage |

## 特色

- 所有收录项目均为**自由软件**（Free Software），非自由软件单独列在 [Non-Free](https://github.com/awesome-selfhosted/awesome-selfhosted/blob/master/non-free.md) 页面
- 自动化死链检测和未维护项目检查
- 每个项目标注编程语言、许可证和 Demo 链接
- 社区活跃维护，持续更新

## 使用方式

推荐使用 [HTML 版本](https://awesome-selfhosted.net/)，支持搜索和筛选。也可以直接浏览 GitHub Markdown 版本。

## 亮点 / 个人评价

自托管领域的"百科全书"，几乎是寻找开源替代方案的第一站。分类极其细致（60+ 类别），项目信息完整（语言、许可证、Demo），配合自动化检测保证列表质量。无论你是想搭建个人博客、私有云盘、邮件服务器还是完整的协作平台，这里都能找到合适的方案。自托管入门和选型的必备参考。
