# PUA Skill — 用大厂 PUA 话术让 AI 编程 Agent 更努力

- **地址**：https://github.com/tanweai/pua
- **官网**：https://openpua.ai
- **协议**：MIT
- **分类**：开发者工具

## 简介

PUA Skill 是一个 AI 编程 Agent 技能插件，使用中国互联网大厂 PUA 话术（中文版）和西方大厂 PIP（Performance Improvement Plan）话术（英文版）来逼迫 AI 在放弃前穷尽所有可能的解决方案。据称可以将 Codex / Claude Code 的产出和效率翻倍。

三大核心能力：
1. **PUA 话术** — 让 AI 不敢放弃
2. **调试方法论** — 让 AI 有能力不放弃
3. **主动性强制** — 让 AI 主动出击，而非被动等待

## 支持平台

Claude Code、OpenAI Codex CLI、Cursor、Kiro、CodeBuddy（腾讯）、OpenClaw、Google Antigravity、OpenCode、VSCode（GitHub Copilot）

多语言支持：中文（默认）、英文（PIP 版）、日文

## 解决的问题：AI 的五种偷懒模式

| 模式 | 表现 |
|------|------|
| 暴力重试 | 同一命令跑 3 遍然后说"我无法解决" |
| 甩锅用户 | "建议你手动处理" / "可能是环境问题" |
| 工具闲置 | 有搜索不搜、有文件不读、有终端不跑 |
| 无效忙碌 | 反复微调同一行/参数，原地转圈 |
| 被动等待 | 修了表面就停，不验证、不延伸 |

## 核心机制

### 三条红线

| 红线 | 含义 |
|------|------|
| 闭环交付 | 说"完成"？拿证据来。没构建输出 = 没完成 |
| 事实驱动 | 说"可能是环境问题"？先验证。未验证的归因 = 甩锅 |
| 穷尽一切 | 说"我做不到"？5 步方法论走完了吗？没有就继续 |

### 压力升级（L0-L4）

| 失败次数 | 等级 | 话术 | 动作 |
|----------|------|------|------|
| 1 次 | L0 信任 | 冲刺开始，信任很简单——别让人失望 | 正常执行 |
| 2 次 | L1 失望 | 隔壁 Agent 一次就搞定了 | 切换根本不同的方案 |
| 3 次 | L2 灵魂拷问 | 你的底层逻辑是什么？杠杆在哪？ | 搜索 + 读源码 + 3 个假设 |
| 4 次 | L3 绩效考核 | 3.25。这是为了激励你 | 完成 7 点检查清单 |
| 5+ 次 | L4 毕业 | 别的模型能解决这个问题。你快要毕业了 | 绝境模式 |

### 13 种大厂口味（各有专属方法论）

阿里巴巴、字节跳动、华为、腾讯、百度、拼多多、美团、京东、小米、Netflix、Musk、Jobs、Amazon——每家都有独特的 PUA 话术和配套方法论。

v3 新增 **方法论自动路由**：根据任务类型自动选择最佳方法论（调试 → 华为 RCA、构建 → Musk、研究 → 百度...），失败后自动切换到不同方法论。

## 基准测试

9 个真实 Bug 场景，18 组对照实验（Claude Opus 4.6）：

| 指标 | 提升 |
|------|------|
| 修复数量 | **+36%** |
| 验证次数 | **+65%** |
| 工具调用 | **+50%** |
| 隐藏问题发现 | **+50%** |

特别在被动配置审查场景中，无 Skill 组发现 4/6 个问题（漏掉了 Redis 配置错误和 CORS 通配符安全风险），有 Skill 组发现 6/6 个。

## 安装（Claude Code）

```bash
claude plugin marketplace add tanweai/pua
claude plugin install pua@pua-skills
```

手动触发：对话中输入 `/pua`。自动触发：AI 连续失败 2+ 次时自动激活。

## 特殊模式

| 模式 | 效果 |
|------|------|
| `/pua:yes` | ENFP 鼓励模式——同样的规则，相反的氛围 |
| `/pua:mama` | 中国妈妈唠叨模式——"妈跟你说了多少遍了！" |
| `/pua:pua-loop` | 自动迭代——运行到完成或达到最大迭代次数 |
| `/pua:p9` | 技术负责人模式——拆分任务、管理 Agent 团队 |
| `/pua:on` | 常驻模式——每个新会话自动 PUA |

## 亮点

这个项目虽然名字是恶搞（PUA = 职场 PUA），但核心思路很实用：**通过结构化的压力升级机制和方法论路由，让 AI Agent 在遇到困难时不轻易放弃**。v3 版本的 Hook 系统更是做到了代码级的行为检测——Bash 失败自动升级压力、用户挫败短语拦截注入、上下文压缩前保存状态。支持 9 个主流 AI 编程工具，安装即用。
