# Job Hunter — AI 辅助求职自动投递

- **地址**：https://github.com/YIKUAIBANZI/job-hunter
- **协议**：MIT
- **分类**：开发者工具

## 简介

一个 Claude Code Skill，读你的简历、记住你的方向和底线，然后在招聘平台上按岗位匹配度自动投递。核心理念：与其广撒网，不如精准慢投，让 AI 只投匹配的岗位。

## 核心能力

- **简历解析**：读取简历文件（`.md`/`.txt`），提取 8-15 个技能关键词，存到本地配置
- **JD 匹配评分**：技能命中 +5 分（上限 +30），目标岗位标题命中 +30 分，排除词命中直接归零
- **多平台支持**：Boss 直聘、鱼泡直聘、前程无忧 51job
- **完整日志**：每次投递记录岗位、评分、动作，避免重复投递

## 评分机制

| 配置项 | 作用 |
|--------|------|
| `skills` | 技能词 → JD 每命中一个 +5 分，上限 +30 |
| `target_roles` | 期望岗位 → 标题命中 +30 分 |
| `exclude_keywords` | 排除词 → 命中直接归零（如"总监"、"架构师"） |
| `boost_keywords` | 加权词 → JD 命中 +10 分（AI/LLM 等） |
| `min_score` | 最低投递分，默认 60 |

## 平台支持

| 平台 | 投递方式 | 城市覆盖 |
|------|---------|---------|
| Boss 直聘 | "立即沟通" | 9 大城市 + 全国 |
| 鱼泡直聘 | "发送简历"优先，降级"聊一聊" | 50+ 城市 |
| 前程无忧 51job | 搜索页内联"投递" | 北上广深杭 |

## 安装使用

```bash
# 克隆到 skills 目录
git clone https://github.com/YIKUAIBANZI/job-hunter.git ~/.claude/skills/job-hunter

# 安装依赖
pip install DrissionPage
```

需要启动远程调试模式的 Chrome 并提前登录各平台。首次运行会引导配置简历路径、期望岗位、排除词等。

也可脱离 Claude Code 直接用 Python 脚本运行：
```bash
python3 boss_apply.py --job "产品经理" --city 深圳 --count 20
```

## Token 消耗

投 100 份岗位的总成本 ≈ 读简历一次（~6K，一次性）+ 每次启动 ~3K。评分匹配纯 Python 规则，不走 LLM，不按岗位数量线性增长。

## 亮点 / 个人评价

定位精准——不做伪造简历、不绕反爬，就是老老实实用本地浏览器帮你按匹配度投。评分机制设计合理，排除词 + 加权词的组合能有效过滤不相关岗位。对不想手动海投的求职者来说是个实用的效率工具。
