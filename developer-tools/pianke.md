# 片刻（Pianke）

- **地址**：https://github.com/zhaoyue4810/pianke
- **作者/团队**：zhaoyue4810
- **协议**：MIT
- **分类**：developer-tools

## 简介

片刻是一款专为摄影师设计的本地照片选片工具。核心功能是将一次拍摄中相似的照片自动归入"同一个瞬间"的组，然后通过左右 A/B 擂台 PK 方式快速挑出最满意的一张。纯本地运行，隐私安全，支持 RAW 格式。

## 核心特性

- **智能废片初筛**：自动识别模糊、过曝、欠曝、闭眼等技术性废片，支持一键复核召回
- **多信号相似分组**：融合 DINOv2 视觉语义、人脸特征识别、EXIF 时间/GPS，精准归组连拍
- **擂台式 PK 选片**：`←`/`→` 键盘快捷键两两对决，极速筛选
- **RAW 原生支持**：RAW+JPG 双拍自动配对同步搬运；纯 RAW 模式毫秒级提取内嵌预览图
- **无损反悔**：多级撤销、整组重选、进度实时持久化，随时中断自动恢复
- **相机水印**：批量添加 EXIF 信息水印，11 种样式，自动匹配品牌 Logo（富士/佳能/尼康/索尼/徕卡等）

## 三种工作模式

| 模式 | 初筛方式 | 分组逻辑 | 依赖 | 联网 |
|------|---------|---------|------|------|
| **极速 (Fast)** | 本地轻量算法 | 感知哈希图像比对 | ~200MB | 不需要 |
| **专家 (Expert)** | 本地 AI（人脸/技术美学） | DINOv2 + 人脸识别 + EXIF 融合 | ~2-3GB | 仅首次下载模型 |
| **土豪 (Tycoon)** | 远程多模态大模型（火山/GPT-4V/Qwen） | 同专家模式 | ~5MB + API Key | 每张图调用 LLM |

选择建议：拍物/风景/低配 → 极速；拍人像/婚礼 → 专家；需要退片理由 → 土豪。

## 选片工作流

1. 导入照片文件夹 → 选择工作模式
2. 系统扫描分析（流式进度显示）
3. 初筛复核：查看被淘汰废片及原因，点击可召回
4. 分组预览：可拖动滑块调节分组阈值
5. 擂台 PK：组内两两对比，键盘操作极速选片
6. 完成导出：展示所有 Winner，一键打开结果文件夹

## 输出目录

```
照片文件夹/
├── winners/                # 胜出照片
├── losers/                 # 淘汰照片
├── .pic_selecter_state.json # 进度持久化
└── _pic_selecter/          # 缓存与日志
```

支持移动模式（默认，省空间）和复制模式（保留原片）。

## 快速开始

```bash
# 方式一：双击启动脚本（非开发者推荐）
# macOS: 启动_macOS.command
# Windows: 启动_Windows.bat

# 方式二：手动启动
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python app.py  # 默认端口 5057，自动打开浏览器
```

## 亮点 / 个人评价

这个工具精准解决了摄影师"一次拍摄几百张、手动选片到眼花"的痛点。三种模式设计很巧妙：极速模式零门槛适合低配，专家模式用 DINOv2 做视觉语义分组对拍人的场景更准，土豪模式用 LLM 给出"人话"退片理由很有意思。擂台式 PK 交互比传统星级评分高效得多。支持 RAW+JPG 配对和品牌水印是专业级别的细节。整体设计理念——"让 AI 协助初筛与分组，把最终的审美决定权留给自己"——定位准确，不越俎代庖。
